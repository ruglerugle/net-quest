STAGE 3

IPアドレスとサブネット

同じネットワークかを判定する
🎯 ミッション
IP アドレスの書き方と、サブネットマスクで同じネットワークかを判定する方法を説明できるようになろう。3組のアドレスを判定し、確認クイズに全問正解すれば合格。
未達成
ねこ博士
MAC アドレスは部品に付いた番号で、並び方に規則が無い。世界中の何十億台もの MAC アドレスを全部覚えている機械は無いから、遠くの相手に届けるには、場所を表す住所が別に必要だ。それが IP アドレスだ。
うさ美
住所なら、「何県・何市・何番地」のように、大きな区切りから順に書いてあるんですか？
ねこ博士
考え方は同じだ。いま広く使われている IPv4 の IP アドレスは32ビットの数で、8ビットずつ4つに区切って10進数で書く。192.168.1.10 のようにね。前半が「どのネットワークか」を表すネットワーク部、後半が「そのネットワークの中のどの機械か」を表すホスト部だ。
うさ美
どこまでがネットワーク部かは、どうやって決めるんですか？
ねこ博士
サブネットマスクで示す。ネットワーク部を1、ホスト部を0にした32ビットの数だ。前から24ビットがネットワーク部なら、255.255.255.0（1が24個、0が8個）。これを短く /24 とも書く。
192.168.1.10 ＝ 11000000.10101000.00000001.00001010 /24（255.255.255.0）＝ 11111111.11111111.11111111.00000000 AND（両方1のときだけ1）＝ 11000000.10101000.00000001.00000000 ＝ 192.168.1.0 ← ネットワークの番号
うさ美
AND を取ると、マスクが0のホスト部は全部0になって、ネットワーク部だけが残る。2つのアドレスで AND の結果が同じなら、同じネットワークにいる、ということですか？
ねこ博士
その通り。同じネットワークなら、スイッチを通して直接届けられる。違うネットワークなら、ルーター（STAGE5）に頼む。送る機械は、送るたびにこの判定をしているんだ。『論理回路CPUクエスト』の AND ゲートが、ここでも働いている。
うさ美
/24 なら、ホスト部は8ビットだから、256台までですか？
ねこ博士
ほぼそうだけれど、2つ使えない番号がある。ホスト部が全部0の番号は「ネットワークそのもの」、全部1の番号は「そのネットワークの全員あて（ブロードキャスト）」を表す決まりなので、機械に付けられるのは 256 − 2 ＝ 254 台だ。
うさ美
32ビットだと、全部で約43億個。世界の人口より少ないですね。スマホもパソコンも1人何台も持っているのに……。
ねこ博士
いいところに気づいたね。IPv4 の住所は、とっくに足りなくなっている。それをどう乗り切ってきたかは STAGE11 の NAT で、本当の答えは STAGE12 の IPv6 で見よう。

確認クイズ

Q1. 10.1.2.3 を /16（255.255.0.0）で AND すると、ネットワークの番号は？

正解！ /16 は前の16ビット（前の2つの区切り）がネットワーク部。後ろ2つが0になって 10.1.0.0。

Q2. 送る機械が「同じネットワークか」を判定する方法は？

正解！ マスクの1の部分（ネットワーク部）だけを取り出して比べる。同じなら直接、違えばルーターへ。

Q3. /24 のネットワークで、機械に付けられる IP アドレスはいくつ？

正解！ ホスト部8ビットで256通り。全部0（ネットワークそのもの）と全部1（ブロードキャスト）を除いて254。
