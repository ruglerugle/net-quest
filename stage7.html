STAGE 7

DNS

名前からIPアドレスを調べる
🎯 ミッション
DNS で名前から IP アドレスを調べる流れと、キャッシュの役割を説明できるようになろう。DNS の問い合わせを最後まで追い、確認クイズに全問正解すれば合格。
未達成
ねこ博士
きみがブラウザに www.example.com と入れても、IP の世界で使えるのは IP アドレスだけだ。名前から IP アドレスを調べる仕組みを DNS（Domain Name System）と呼ぶ。
うさ美
電話帳のようなものですね。でも、世界中の全部の名前を1冊の電話帳に載せたら、大きすぎて、それに毎日書き換わりますよね。
ねこ博士
そう。だから DNS は、名前を区切りごとに担当を分けている。名前は右から読むんだ。www.example.com なら、一番右の「.com」を担当するサーバーがあって、そのサーバーは「example.com の担当はあのサーバー」と知っている。example.com の担当サーバーが、www.example.com の IP アドレスを知っている。
うさ美
一番右より、さらに右があるんですか？ .com の担当を知っている人は？
ねこ博士
一番上にルート（根）と呼ばれるサーバーがあって、「.com の担当」「.jp の担当」を知っている。世界に13の名前で、実際には何千台もの機械が分担している。
ルート（.）→ .com の担当 → example.com の担当 → www.example.com の IP アドレス きみのスマホの代わりに、たずね回る係を DNS キャッシュサーバー（リゾルバ）と呼ぶ。DHCP で教わった DNS サーバーがこれ
うさ美
スマホは1回たずねるだけで、たずね回るのはキャッシュサーバーなんですね。毎回ルートからたずねたら、ルートが大忙しになりそう。
ねこ博士
そこでキャッシュが効く。キャッシュサーバーは、一度調べた答えを、答えに付いている期限（TTL。STAGE5 の TTL とは別のもので、こちらは秒数）のあいだ覚えておく。.com の担当がどこかも覚えておくので、ほかの .com の名前をたずねるときは、ルートを飛ばせる。スマホやブラウザ自身も、少しのあいだ覚えている。
うさ美
期限があるのは、サーバーの引っ越しで IP アドレスが変わることがあるからですか？
ねこ博士
そう。期限が長すぎると引っ越しがなかなか伝わらず、短すぎるとたずね直しが増える。管理する人が、その名前ごとに決めているんだ。

確認クイズ

Q1. DNS の役割は？

正解！ IP アドレス → MAC アドレスは ARP、住所を配るのは DHCP。

Q2. www.example.com を調べるとき、最初にたずねる担当（キャッシュに何も無い場合）は？

正解！ 名前は右から読む。一番上のルートが .com の担当を教え、.com の担当が example.com の担当を教える。

Q3. DNS キャッシュに期限（TTL）がある理由は？

正解！ 覚えておけば速いが、古いままでは困る。期限で「どれくらい信じてよいか」を決めている。
