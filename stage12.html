IPv6

住所が足りない問題の本当の答え
🎯 ミッション
IPv6 の住所の大きさ・書き方と、IPv4 との違いを説明できるようになろう。IPv6 の住所の省略を3問正しく選び、確認クイズに全問正解すれば合格。
未達成
ねこ博士
IPv4 の住所は32ビットで約43億個だった。そこで、もっと大きな住所を使う新しい IP が作られた。IPv6 だ。住所は128ビットある。
うさ美
32ビットから128ビット……。1ビット増えるごとに2倍だから、2を96回掛けた倍、増えている。とんでもない数ですね。
ねこ博士
2を128回掛けると、約3.4×10の38乗。地球の砂粒の数よりはるかに多い。家の中の電球1つ1つにまで、世界に1つの住所を配れる大きさだ。
ねこ博士
128ビットを書くために、16ビットずつ8つに区切り、それぞれを16進数4けたで書いて、コロン（:）でつなぐ。
例：2001:0db8:0000:0000:0000:0000:0000:0001 省略ルール①：各区切りの先頭の0は省ける（0db8 → db8、0000 → 0） 省略ルール②：0 だけの区切りが続くところを、1か所だけ :: にまとめられる → 2001:db8::1
うさ美
:: を2か所に使えないのは、なぜですか？
ねこ博士
何個の区切りをまとめたのかが分からなくなるからだ。全部で8つの区切りと決まっているので、:: が1つなら「残りが何個か」から逆算できる。2つあったら、どちらに何個入っているか決められない。
うさ美
IPv6 なら、NAT はいらないんですか？
ねこ博士
住所が足りないから NAT で使い回していたので、IPv6 では、家の中の機械も1台ずつ世界に1つの住所を持てる。外からつながるかどうかは、住所の書き換えではなく、STAGE14 のファイアウォールで「何を通すか」を決めて守る。インターネットが本来目指していた「どの機械とも直接つながれる」形に戻るわけだ。
ねこ博士
ほかにもいくつか良くなった点がある。IPv6 には ARP が無く、代わりに「近くの機械を探す」決まり（近隣探索）が IPv6 の中に組み込まれている。DHCP サーバーが無くても、ルーターから教わったネットワークの番号に自分で番号を足して、住所を自分で作ることもできる。
うさ美
じゃあ、もう全部 IPv6 になっているんですか？
ねこ博士
なっていない。IPv4 と IPv6 は直接は話せないので、いまは両方を同時に使える機械やサービスが多い（デュアルスタックと呼ぶ）。日本でも、スマホの通信や家の光回線では IPv6 がかなり広がっているけれど、IPv4 だけのサービスも残っていて、移行は何十年もかけて少しずつ進んでいるところだ。

確認クイズ

Q1. IPv6 の住所の長さは？

正解！ IPv4 は32ビット、IPv6 は128ビット。2を128回掛けた数（約3.4×10の38乗）だけ住所がある。

Q2. 2001:0db8:0000:0000:0000:0000:0000:0001 の正しい省略は？

正解！ 各区切りの先頭の0を省き、0 だけの区切りが続くところを1か所だけ :: にする。区切りの中の、先頭以外の0は省けない（2001 は 21 にならない）。

Q3. IPv6 で NAT が基本的に要らない理由は？

正解！ NAT は住所不足の対策だった。IPv6 では使い回す必要がなく、守りはファイアウォールで行う。
