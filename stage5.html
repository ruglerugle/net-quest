STAGE 5

ルーター

ネットワークをまたいで届ける
🎯 ミッション
ルーターの中継で、何が書き換わり何が変わらないかを説明できるようになろう。ルーターを2台またぐ通信を最後まで追い、確認クイズに全問正解すれば合格。
未達成
ねこ博士
PC-A（192.168.1.10/24）から、別のネットワークにある Web サーバー（203.0.113.5）に送りたい。STAGE3 の判定では「違うネットワーク」だ。どうする？
うさ美
ルーターに頼む、でした。でも、どのルーターに頼めばいいかは、どうやって知るんですか？
ねこ博士
PC には「自分のネットワークの外へ出るときは、このルーターに渡す」という出口のルーターの IP アドレスが設定されている。これをデフォルトゲートウェイと呼ぶ。PC-A は、ARP でゲートウェイの MAC アドレスを調べ、フレームのあて先 MAC をゲートウェイにして送る。ただし、中の IP のあて先は Web サーバーのままだ。
フレームの中身は2重になっている：［MAC あて先・送り元］［ IP あて先・送り元・TTL ［データ］］ MAC：この区間で次にだれに渡すか　／　IP：最終的にだれに届けたいか
ねこ博士
ルーターはフレームを受け取ると、中の IP あて先を見て、経路表（どのネットワークへは、どの方向の次のルーターに渡せばよいかの表）で次の渡し先を決める。そして、MAC アドレスを書き換えて送り出す。
うさ美
MAC アドレスは区間ごとに書き換わるけれど、IP アドレスは最初から最後まで同じ。MAC は「次の人」、IP は「最後の人」を表しているから、ということですか？
ねこ博士
その通り。これが STAGE1 の層の分け方の実例だ。データリンク層（MAC）は1区間を、ネットワーク層（IP）は端から端までを受け持つ。
うさ美
IP の部分に書いてある TTL というのは何ですか？
ねこ博士
Time To Live（生きていられる時間）の略で、実際には「あと何回ルーターを通ってよいか」の回数だ。ルーターは通すたびに1減らし、0 になったらそのパケットを捨てる。経路表の設定ミスで、ルーターの間をぐるぐる回り続けるパケットが出ても、いつかは消えるようにするための安全装置なんだ。
うさ美
インターネットのルーターは、世界中のネットワークへの経路を全部知っているんですか？
ねこ博士
家のルーターは「自分のネットワーク以外は、全部プロバイダのルーターへ」という1行で足りる。インターネットの中心にあるルーターどうしは、どのネットワークへどう行けるかの情報を交換しあって、経路表を自動で作り直し続けている。どこかの線が切れても、別の道を見つけられるようにね。

確認クイズ

Q1. ルーターが中継するときに書き換えるのは？

正解！ MAC は「この区間で次にだれに渡すか」なので区間ごとに変わる。IP あて先は最終目的地なので変わらない。TTL は1ずつ減る。

Q2. デフォルトゲートウェイとは？

正解！ 違うネットワークあてのパケットは、まずデフォルトゲートウェイに渡す。

Q3. TTL が0になったパケットをルーターが捨てる理由は？

正解！ TTL は通ってよいルーターの数。回り続けても、いつかは消える安全装置。
